## Research: market values by ISIN (B3)

- **BSE Debt bhavcopy** — `https://www.bseindia.com/download/BhavCopy/Debt/DEBTBHAVCOPY<ddmmyyyy>.zip`,
  ~30 KB, three CSVs. `icdm*.csv` is the corporate debt list: `ISIN No.`, `Issuer Name`,
  `Coupon`, `Maturity Date`, `LTP`, `Weighted Average Yield`, `Face Value`. LTP is a percentage
  of face value, so value = units × face value × LTP / 100. It answers only with a `Referer`
  header, which a browser cannot set on `fetch`, but the local server can.
- **NSE** publishes a comparable debt bhavcopy; same shape, same CORS problem, similar coverage.
- **Yahoo/Google style feeds** do not carry Indian corporate bonds by ISIN.
- **Coverage measured on 9 trading days** for the six ISINs visible in the review screenshots:
  1 ISIN priced on 7 days, 2 on a single day, 3 never. Illiquid hold-to-maturity paper simply
  does not trade, which is why "market value" is empty rather than zero.

Proposed shape: `GET /__market/debt?isins=...&days=10` on the local server returns the most
recent LTP and its date per ISIN, cached under `data/market/`. The bond page gets
`Fill market values from BSE`, marks each filled lot `from BSE · 23 Oct`, and leaves
everything else untouched. Manual prices remain the primary path for untraded lots.

## Rating sources, checked 28 Oct 2026

- **SMEST** (`smest.in/bond-details/<slug>/<ISIN>`) is server-rendered and needs no key. The
  slug is not checked: `https://smest.in/bond-details/x/<ISIN>` returns the same page. A plain
  fetch of three ISINs from the ledger returned the agency and rating every time
  (`ICRA · A / Stable`, `ACUITE · A / Stable`, `CRISIL · A / Stable`). The page also carries
  maturity, coupon, next interest date, allotment date, NSDL/CDSL, guarantee, mode of issue and
  issuer type. About 140 KB per bond, so a dozen bonds is under 2 MB per refresh.
- **NSE CRD** (`nseindia.com/companies-listing/debt-centralised-database/crd`) has a
  `Download (.csv)` that is a client-side export of a JS-loaded table; no stable ISIN-keyed
  endpoint was visible in the page or its module. Usable only with a headless browser.
- Caveats for SMEST: it is a broker's catalogue, so scraping is subject to their terms, the
  route is not a public contract, and coverage is only bonds they list. Cache one fetch per
  bond per day and fail soft.
